# Recall

Use the configured `basic-memory` MCP server and project `knowledge` at https://bm.asylcreek.xyz/mcp.

Do not run startup recall, load notes during unrelated tasks, or create or update records. If the server is unavailable, report that retrieval did not complete.

1. Search for the user's topic, then read only the relevant records. Narrow by system, project, or date when useful. Do not load the entire knowledge base.
2. Answer with the relevant findings and their memory URLs. Distinguish the original observation date from the present. Say when no relevant record exists.
3. Treat saved fixes as historical evidence. Check current state before recommending or applying an infrastructure change. Retrieval alone does not authorize a change.

Use the server's advertised search/read tools and their current schemas.
